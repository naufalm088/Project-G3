# Think Aloud — Panduan Pengujian Usabilitas
## Smart Kos Monitor (Kelompok G3)

## 1. Tujuan

- Menilai kemudahan penggunaan dashboard monitoring kos (kamar, penghuni, pembayaran, CCTV) oleh pemilik kos.
- Mengidentifikasi hambatan kognitif, kebingungan label/ikon, kesalahan interaksi.
- Memvalidasi alur utama: cek pendapatan, status kamar, tagih WA, tandai lunas, lihat CCTV, ubah pengaturan.

## 2. Partisipan

- 5–8 pemilik/pengelola kos (usia 30–60), tidak harus melek teknologi.
- Kriteria: mengelola minimal 4 kamar, pernah menagih sewa bulanan.
- Durasi: 30–45 menit per sesi.

## 3. Perangkat & Lingkungan

- Smartphone Android (layar 6–6.7") dan/atau laptop (untuk uji responsif).
- Aplikasi mode demo atau produksi (URL Vercel).
- Perekaman: screen recorder + audio + catatan observer.

## 4. Tugas (Tasks)

1. **T1 — Pendapatan**: "Berapa pendapatan terkumpul bulan ini dan berapa targetnya?"
2. **T2 — Status kamar**: "Kamar mana yang belum lunas? Siapa penghuninya?"
3. **T3 — Tagih WA**: "Kirim tagihan WA ke penghuni kamar yang belum lunas."
4. **T4 — Tandai lunas**: "Tandai kamar 1 sebagai lunas."
5. **T5 — Edit kamar**: "Ubah nama penghuni kamar 2 dan nomor WhatsApp-nya."
6. **T6 — CCTV**: "Lihat siaran CCTV kos."
7. **T7 — Mode tampilan**: "Ubah tampilan ke mode Modern 3D dan putar view."
8. **T8 — Pengaturan**: "Ubah tanggal jatuh tempo menjadi tgl 10 dan simpan."
9. **T9 — Riwayat**: "Unduh laporan pembayaran bulan ini (PDF)."
10. **T10 — Kamar kosong**: "Tandai kamar 5 sebagai kosong."

## 5. Prosedur

1. Sambutan & penjelasan think aloud (5 menit).
2. Persetujuan perekaman.
3. Pre-test kuesioner (pengalaman teknologi, kebiasaan tagih).
4. Pelaksanaan tugas T1–T10 (think aloud), observer mencatat waktu, kesalahan, utterance.
5. Post-test: SUS (target ≥ 68) + wawancara.
6. Debrief.

## 6. Metrik

- Task success rate (% selesai tanpa bantuan).
- Time on task (detik).
- Error rate (klik salah / salah baca).
- SUS score (target ≥ 68).
- Kutipan think aloud (navigasi, label/ikon, feedback, kepercayaan data).

## 7. Etika

- Data anonim, partisipan boleh berhenti kapan saja.
- Hasil hanya untuk perbaikan produk akademik.
